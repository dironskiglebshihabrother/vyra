# Знак и системные иконки

Концепция выбрана 20 ноября 2026 года. Весь набор собирается из векторной геометрии скриптом.

## Концепция «Слои»

Две пластины со скруглёнными концами наклонены навстречу друг другу и пересекаются внизу. Вместе они образуют букву V. Правая пластина полупрозрачна и лежит поверх левой, поэтому на пересечении получается третий тон.

Две пластины отвечают слогану: музыка и пространство. Интерфейс VYRA устроен так же, панели и виджеты лежат слоями.

Отклонённые концепции перечислены в решении Р18 в [decisions.md](../architecture/decisions.md).

## Геометрия

Пластина представляет собой прямоугольник с полностью скруглёнными концами. Обе пластины повёрнуты вокруг общего центра нижнего скругления: левая на −23°, правая на +23°. Подложки под знаком нет.

Знак подгоняется под каждый размер отдельно. Чем меньше иконка, тем толще пластины и меньше поля:

| Размер, px | Поле, px | Радиус пластины, доля высоты знака |
| --- | --- | --- |
| 16 | 0,5 | 0,19 |
| 20 | 1 | 0,19 |
| 24 | 1 | 0,185 |
| 32 | 1,5 | 0,18 |
| 40 | 2 | 0,172 |
| 48 | 3 | 0,166 |
| 64 | 4 | 0,162 |
| 256 | 16 | 0,162 |

Числа лежат в таблице `MARK_TUNING` в начале скрипта сборки.

## Цвета

| Часть | Значение |
| --- | --- |
| Левая пластина | `#b3a6dc` |
| Правая пластина | `#6a5aa8`, непрозрачность 78% |
| Пересечение | получается наложением, `#7a6bb3` |
| Лист в иконках файлов | `#efe9de`, загиб `#d9d1c2`, кромка `#cbc2b1` |
| Знак на листе | `#9d8fd6` и `#5f4f9e`, непрозрачность 85% |
| Полоса формата | `#6a5aa8`, подпись `#efe9de` |

У пластин разная светлота, поэтому знак виден на любой панели задач: на тёмной его держит левая пластина, на светлой правая.

На светлом листе бледная левая пластина терялась бы, поэтому в иконках файлов пара тонов темнее.

## Состав набора

Всё лежит в `tools/icons/dist`.

| Файл | Содержимое |
| --- | --- |
| `vyra.ico` | иконка приложения, размеры 16, 20, 24, 32, 40, 48, 64, 256 |
| `tray/tray-white.ico`, `tray/tray-black.ico` | иконка трея для тёмной и светлой панели задач, размеры 16, 20, 24, 32 |
| `files/<формат>.ico` | 15 иконок типов файлов, по 8 размеров |
| `mark.svg`, `vyra-256.png` | знак в векторе и в растре для документации и интерфейса |
| `preview.png` | контрольный лист: все размеры на тёмном и светлом фоне |

Форматы: MP3, FLAC, WAV, AIFF, M4A, AAC, OGG, OPUS, WMA, APE, WV, DSF, DFF, AC3, DTS. ALAC хранится в файлах `.m4a` и отдельной иконки не имеет.

Правила по размерам:

- подпись формата появляется на листе с 48 px, мельче она нечитаема;
- на 16–40 px лист несёт только знак и узкую сиреневую полосу внизу;
- иконка трея с 24 px имеет тонкий зазор между пластинами, на 16 и 20 px знак сплошной.

Кнопки на миниатюре в панели задач используют обычные значки воспроизведения и из знака не выводятся.

## Движение

Две вертикальные пластины стоят как знак паузы. Затем они наклоняются и сходятся в V. Обратный ход возвращает паузу.

Где это применяется:

- заставка при запуске;
- установщик: угол раскрытия пластин показывает ход установки, от сложенных вместе до полного V;
- индикатор загрузки: пластины покачиваются.

Анимируются только поворот и непрозрачность, это укладывается в бюджет 60 кадров из [ui-customization.md](../architecture/ui-customization.md).

## Сборка

```
cd tools/icons
npm install
npm run build
```

Скрипт `build.mjs` строит SVG для каждого размера, растеризует его через `@resvg/resvg-js` и сам упаковывает `.ico`. Размер 256 px хранится внутри как PNG, остальные как 32-битные растры: так файл читают все части оболочки Windows.

Подписи форматов набраны шрифтом Segoe UI, поэтому собирать набор нужно на Windows.

## Что ещё не проверено

Файлы открываются средствами Windows, цвета пикселей совпадают с заданными. В настоящей панели задач и в проводнике иконки не проверялись: для этого нужны исполняемый файл и регистрация типов, они появятся вместе с установщиком.

На 16 px знак на листе занимает около восьми пикселей и читается слабо. Если в проводнике это будет мешать, для этого размера стоит рисовать знак одним тоном.
