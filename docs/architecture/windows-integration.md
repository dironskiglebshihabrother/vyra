# Windows: окно, установщик, системная интеграция

Документ покрывает три требования, добавленные после исходного брифа: собственные кнопки окна, установщик с анимациями и системные иконки в стиле Windows. Сюда же собрано остальное, что связывает VYRA с системой.

## Окно без системной рамки

Главное окно, мини-плеер и окно установщика создаются с `decorations: false` и `shadow: true`. Тень и скруглённые углы Windows 11 при этом сохраняются. Заголовок рисует React: область перетаскивания и три кнопки, оформленные токенами темы. Компонент заголовка лежит в общем пакете `packages/ui` и одинаков в приложении и в установщике.

Убирая системную рамку, легко потерять поведение, к которому пользователь привык. Список того, что обязано работать:

| Поведение | Как обеспечивается |
| --- | --- |
| Перетаскивание окна, двойной щелчок по заголовку | область `data-tauri-drag-region` |
| Изменение размера за края | Tauri обрабатывает края окна без рамки сам; проверить ширину зоны захвата на экранах с масштабом 150% и 200% |
| Win + стрелки, прилипание к краям | сохраняются, пока у окна есть стиль `WS_THICKFRAME` |
| Меню раскладок Snap при наведении на кнопку «Развернуть» в Windows 11 | фронтенд передаёт в Rust прямоугольник кнопки, обработчик `WM_NCHITTEST` возвращает для него `HTMAXBUTTON` |
| Системное меню по Alt + Пробел и правому щелчку на заголовке | вызывается из Rust через `GetSystemMenu` |
| Развёрнутое окно не выходит за края экрана и не перекрывает панель задач | обработка `WM_GETMINMAXINFO` |
| Клавиатура и экранный диктор | кнопки доступны с Tab, имеют имена «Свернуть», «Развернуть», «Закрыть» |
| Режим высокой контрастности | кнопки берут системные цвета через `forced-colors` |

Меню раскладок Snap считается главным риском: кнопка нарисована в HTML, а система ждёт ответа от оконной процедуры. Это проверяется прототипом П8 до начала работы над оболочкой.

Средняя кнопка разворачивает окно. Настоящий полноэкранный режим без панели задач включается по F11 и командой меню.

Кнопка закрытия по умолчанию убирает окно в трей, музыка продолжает играть. Поведение меняется в настройках на выход из программы.

## Установщик

### Что требуется

Установщик выглядит как часть VYRA: то же окно без рамки со своими кнопками, те же шрифты и токены, анимации в 60 кадров в секунду.

### Ограничение, из которого растёт конструкция

Стандартные средства Tauri собирают установщик на NSIS или WiX. Оба рисуют классические диалоги Windows. Сменить в них картинки можно, получить собственное окно с анимациями нельзя.

Интерфейс установщика удобнее всего сделать тем же способом, что и приложение: WebView2 и общий пакет `packages/ui`. Тогда внешний вид совпадает до пикселя, а анимации пишутся один раз. Но WebView2 есть не на каждой машине. В Windows 11 он встроен, в Windows 10 обычно установлен вместе с Edge, без гарантии.

### Предлагаемая конструкция

```
VYRA Setup.exe (Rust, около 10 МБ без полезной нагрузки)
  1. Проверка WebView2
       есть  → шаг 2
       нет   → малое нативное окно с логотипом и полосой хода работы,
               установка WebView2, затем шаг 2
  2. Окно установщика на WebView2: приветствие, параметры, ход установки, готово
  3. Движок установки в фоновом потоке, события хода работы идут в окно
```

Нативное окно шага 1 рисуется через Direct2D и содержит только логотип, строку состояния и полосу. Оно появляется редко, поэтому делается простым.

Для движка установки есть два варианта.

**Вариант А.** Своё окно управляет проверенным движком в тихом режиме. Tauri собирает обычный пакет NSIS, `VYRA Setup.exe` несёт его внутри и запускает с ключом `/S`. Копирование файлов, запись об удалении и ярлыки выполняет NSIS. Ход работы известен по этапам, точного процента нет. Удаление устроено так же: команда удаления в системе указывает на `VYRA Setup.exe --uninstall`, который показывает своё окно и тихо запускает деинсталлятор NSIS.

**Вариант Б.** Собственный движок на Rust: распаковка архива в `%LOCALAPPDATA%\Programs\VYRA`, ключи реестра, ярлыки, откат при ошибке. Даёт точный ход работы и один исполняемый файл на установку, обновление и удаление. Цена: две-три недели разработки и долгий хвост редких случаев вроде занятых файлов и антивирусов.

Рекомендация: начать с варианта А. Установка занимает секунды, поэтапной индикации для красивой анимации достаточно. К варианту Б стоит переходить, только если прототип П9 покажет, что поэтапная схема выглядит плохо. Вместо NSIS в варианте А можно взять Velopack, у него быстрые разностные обновления; это имеет смысл оценить, когда появится канал обновлений. Выбор записан в решении Р14.

### Установка без прав администратора

По умолчанию VYRA ставится для текущего пользователя в `%LOCALAPPDATA%\Programs\VYRA` и пишет только в `HKCU`. Запрос UAC не появляется, окно установщика не прерывается системным диалогом.

### Автономная установка

WebView2 можно доставить двумя способами: загрузчик на 2 МБ, которому нужен интернет, или полный пакет около 130 МБ внутри установщика. Для продукта с принципом local-first логично выпускать обе редакции: малую онлайн и полную автономную.

### Подпись кода

Неподписанный установщик Windows встречает предупреждением SmartScreen на весь экран. Анимации пользователь увидит уже после него. Сертификат подписи нужен к первому публичному выпуску, решение Р14.

### Экраны

Четыре экрана: приветствие, параметры (папка, ярлыки, типы файлов, пакет кодеков), ход установки, завершение с кнопкой запуска. Визуальная концепция и анимации разрабатываются по unslop после согласования направления.

Работа движка идёт в отдельном потоке и не касается потока интерфейса. Анимируются только `transform` и `opacity`, как и в приложении.

## Типы файлов

Для каждого формата регистрируется собственный ProgID (`VYRA.flac`, `VYRA.mp3` и так далее) в `HKCU\Software\Classes` со своей иконкой и командой открытия. VYRA добавляется в `RegisteredApplications` с перечнем поддерживаемых типов, после чего появляется в системном разделе «Приложения по умолчанию» и в меню «Открыть с помощью».

Windows 10 и 11 не позволяют программе назначить себя обработчиком по умолчанию без участия пользователя. Флажок в установщике регистрирует типы и открывает системную страницу выбора. Обещать в интерфейсе больше нельзя.

Для папок добавляется команда контекстного меню «Играть в VYRA».

Регистрацию выполняет код в `vyra-platform`, общий для установщика и настроек приложения. После изменения вызывается `SHChangeNotify`, чтобы проводник обновил иконки.

## Иконки

Набор, который нужен системе:

| Назначение | Размеры, px | Примечание |
| --- | --- | --- |
| Иконка приложения, `vyra.ico` | 16, 20, 24, 32, 40, 48, 64, 256 | панель задач, меню «Пуск», проводник, Alt + Tab |
| Иконки типов файлов, по одной на формат | те же | лист с загнутым углом, знак VYRA, подпись формата с 32 px |
| Иконка в трее | 16, 20, 24, 32 | одноцветная, светлый и тёмный вариант под тему панели задач |
| Кнопки на миниатюре в панели задач | 16, 20, 24, 32 | назад, играть, пауза, вперёд; одноцветные |
| Иконка установщика | как у приложения | тот же знак |

Весь набор собирается из векторной геометрии скриптом `tools/icons/build.mjs`, растровых мастеров нет. Знак подгоняется под каждый размер отдельно: на 16–32 px пластины толще, поля меньше.

Пятнадцать иконок типов файлов по восемь размеров отличаются только подписью формата. Подпись появляется с 48 px.

Знак выбран: концепция «Слои». Геометрия и промпты для генерации лежат в [icons.md](../design/icons.md).

## Остальная интеграция

**Один экземпляр.** Повторный запуск передаёт аргументы работающему процессу. На этом построено открытие файлов из проводника, см. [playback-context.md](playback-context.md).

**Системные элементы управления мультимедиа.** SMTC даёт карточку трека с обложкой в системной панели громкости и на экране блокировки, а также мультимедийные клавиши. Интеграция идёт через крейт `souvlaki` или напрямую через `windows`. SMTC привязывается к окну, поэтому ядро держит для него отдельное невидимое окно: карточка продолжает работать, когда интерфейс закрыт в трей.

**AppUserModelID** задаётся явно. От него зависят группировка на панели задач, имя и иконка в SMTC и в уведомлениях.

**Панель задач.** Кнопки на миниатюре окна через `ITaskbarList3`. Список переходов с последними альбомами и плейлистами можно добавить позже.

**Трей.** В MVP меню системное, оно не стилизуется. Собственное всплывающее окно в стиле приложения делается позже отдельным малым окном WebView2.

**Глобальные горячие клавиши.** `tauri-plugin-global-shortcut`. Если сочетание занято другой программой, настройки сообщают об этом рядом с полем.

**Уведомления.** Сообщение о смене трека по умолчанию выключено: его дублирует карточка SMTC.

**Сон системы.** Пока идёт воспроизведение, ядро держит запрос `PowerCreateRequest`, и компьютер не засыпает посреди альбома. На паузе запрос снимается.

**Обновления.** `tauri-plugin-updater` с собственным окном в стиле приложения. Проверка обновлений отключается в настройках, без сети программа работает полностью. Где размещать обновления, записано в решении Р14.
